# FAQ item
**Element:** native `<details>` and `<summary>`. The question is the summary (body size, weight 600) with a decorative plus or minus indicator.

**Tokens:** surface `surface-container`; radius `radius-card`; minimum height 64px; padding `container-padding`.

**Behaviour:** toggles instantly; several can be open at once. No arrow, because opening an answer doesn't move you on.
