# pepperplane.com CTA measurements (read live in the browser pane, 2026-10-24)
Source: getComputedStyle on the live page. Observed facts only.

- Font: Rethink Sans, 16px, weight 600 on all CTAs.
- Shape: 12px radius rectangle (not a pill). Padding 16px 24px (16px 16px 16px 24px when an arrow icon sits on the right).
- Primary: solid white fill, black text on the dark hero ("Let's connect", border 0.8px solid #333); solid #1A1A1A fill, white text for "Book a call" on light sections.
- Secondary: no fill, no border, white text with a right arrow ("See our work").
- Header CTA: "Partner with us" with an arrow, always visible.
- Tertiary: plain text link "Learn more", 400 weight, 0 padding.
- Labels seen: Partner with us, Let's connect, See our work, Learn more, Scale with us, Launch with us, Collaborate with us, See all services, View case study, View all case studies, Book a call, Send a message, Sign up.
- Pattern: 2 to 4 words, verb first, "with us" on partnership actions, one primary and one arrow-link secondary per block, closing CTA block repeats the primary.

Not observed: hover and focus states, motion, mobile layout (not yet checked).
Note: pepperplane is a design agency with no cart, so it informs CTA look, labels and page rhythm only, not shop patterns.
